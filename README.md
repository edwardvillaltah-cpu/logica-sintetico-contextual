## 1. PRESENTACIÓN DE LA OBRA
La **Lógica Sintético-Contextual (LSC-FSC-CALC)** es un marco formal y computacional diseñado para superar las limitaciones de los sistemas lógicos clásicos bivalentes ante escenarios de alta complejidad, asimetría de información y tensión normativa. El sistema integra el análisis de marcos pragmáticos ($C_k$), la ponderación rigurosa de evidencia ($\mathcal{E}$) y la protección estricta de las condiciones basales de sustentabilidad mediante el principio de no compensación ($VI_2 \le VI_1$).

## 3. PRINCIPIO RECTOR: NO COMPENSACIÓN CRÍTICA

El núcleo operativo del sistema se rige por el axioma fundamental de no compensación:

$$VI_2 \le VI_1$$

Este principio impide formalmente que el incremento de utilidad o beneficios en variables secundarias ($VI_2$) justifique la degradación o el sacrificio de las variables de sustentabilidad primaria ($VI_1$).
